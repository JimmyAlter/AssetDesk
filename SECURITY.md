# Security policy

AssetDesk is a portfolio project. The live demo holds only seeded, fictional data and resets whenever the API restarts. Please don't use it to store anything real.

## Reporting a vulnerability

Please don't put vulnerability details in a public issue. Contact the maintainer through the details on the [GitHub profile](https://github.com/JimmyAlter), or open an issue that only asks for a private contact. Include the steps to reproduce and the impact you see. I'll acknowledge the report as soon as I can and credit you in the fix if you'd like.

## Scope

In scope: the code in this repository (the Express API in `backend/` and the React app in `frontend/`).

Out of scope: denial of service against the free-tier demo, findings that need a compromised machine or browser, and issues in third-party services (Render, Vercel, GitHub).

## Supported versions

Only the latest commit on `main` is maintained.
